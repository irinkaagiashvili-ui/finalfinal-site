Installation

FinalFinal installs through the Adobe Creative Cloud Marketplace, the same way as any other Creative Cloud plugin:

  1. Open the Creative Cloud desktop app.
  2. Go to the Marketplace (or Plugins) tab.
  3. Search for FinalFinal.
  4. Select the edition you need — Digital, Print, or Complete — and install it.
  5. Restart Adobe Illustrator if it was already open.
Each edition is its own installation. If you need both digital and print checks, install the Complete edition rather than installing Digital and Print separately.

Finding the panel

Once installed, open the panel from inside Illustrator:

Window → Extensions (Legacy) → FinalFinal — Campaign QA

The panel docks like any other Illustrator panel — drag it into your workspace, or leave it floating.

Quick Scan

Quick Scan is an instant hygiene check on the document you already have open — no profile or setup required. It checks the basics: fonts, images, text, and links.

From the Scan tab, click Quick Scan — no setup.

Full QA

Full QA runs a complete check against a saved profile, across every artboard in the campaign. Use it when you want consistent, repeatable checks — for example, the same brand rules applied to every artboard in a 40-artboard campaign.

  1. On the Scan tab, choose or create a Campaign profile.
  2. Set the Scan scope (all artboards, or a specific range) and, if relevant, a Reference artboard for consistency checks.
  3. Click Run Campaign QA.

Digital, Print & Complete

Under What are you checking?, pick the mode that matches your output:

  • Digital — web, social, screen, and online delivery.
  • Print — print, editorial, packaging, and production.
  • Complete — digital and print checks together, in one pass.

Which modes are available depends on the edition you installed. If a mode shows a lock icon, it isn't included in your installed edition.

Working with results

After a scan, the Results tab lists every issue found, grouped and filterable by severity and category.

  • Locate — jumps straight to the object that caused the issue, on the correct artboard.
  • Mute — hides an issue you've reviewed and decided to ignore, for this document. Muted issues stay hidden until you unmute them or clear all muted issues from the Settings tab.
  • Re-scan — runs the check again with the current profile and scope, so you can confirm a fix worked.

Profiles

A profile defines the rules for a Full QA scan: roles, fonts, colors, and tolerances. Set one up once for a campaign or client, then reuse it for every file. Edit or create profiles from the Profiles tab.

Export

The Export tab batch-exports every artboard in one pass, in any combination of:

  • PNG (with optional transparency)
  • JPG
  • SVG
  • PDF
  • TIFF
  • AI (a copy of your saved file)

Troubleshooting

The panel doesn't appear in the Window menu

Fully quit and reopen Illustrator after installing. If it still doesn't appear, confirm the installed edition matches your Illustrator version, and check for an available Illustrator update.

A scan is taking a while on a large file

This is expected on campaigns with many artboards, images, or text frames — FinalFinal checks every artboard, not a sample. Progress continues in the background; avoid closing the document mid-scan.

"Locate" can't find an object

The object may have been moved, renamed, or deleted since the scan ran. Re-scan the document and use Locate again on the fresh results.

A mode shows a lock icon

That mode isn't included in your installed edition. Install the Complete edition for both digital and print checks.
